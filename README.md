# Paya EP09 Mobile

Android-first Flutter application for «توسعه فناوری پایا همسان».

## Cloud build
The repository contains `codemagic.yaml`. The workflow first generates the Android platform with the fixed organization ID `com.payahamsan`, then builds a release APK.

Expected APK artifact:
`build/app/outputs/flutter-apk/app-release.apk`
